# Omarchy Friends 👥

**Signals, not feeds: a local-first human layer for Omarchy.**

Omarchy Friends makes nearby, opted-in builders visible from the bar. Join an
optional gathering room, share a small project beacon, send a hello, and invite
a real peer to co-work — without accounts, a hosted relay, a global activity
feed, or invented users.

The product rule is simple: an empty radar is honest. A peer appears only after
another running installation broadcasts its presence on the same local network.

## What it does

* **📡 Local Radar:** Discovers recent peers through UDP broadcast on port
  42424. Presence expires after 90 seconds, so “online” means recently seen.
* **🚀 Project Beacons:** Optionally share a short project name, description,
  and URL alongside a coarse status and focus duration.
* **🤝 Trusted Friends:** Save a real peer with a memorable OMAR-XXXX-XXX
  Friend Code. Codes identify a peer; they are not authentication secrets.
* **✨ Shared Ground:** Pick up to four bounded interests such as Linux, open
  source, design, music, or hardware. Matching prioritizes overlap and shows
  exactly why a peer is relevant.
* **🪩 Gathering Rooms:** Enter a shared nickname such as `friday-hack-night`
  for a meetup-sized radar. Rooms are manual, optional, local-only, and never
  inferred from location.
* **✋ Small human signals:** Send high-fives, coffee breaks, kudos, setup
  signals, or a warm hello that includes a bounded shared-ground opener. There
  is no freeform chat or simulated auto-reply.
* **🍅 Co-work:** Start a private focus session or send an explicit invite to a
  nearby peer. The recipient chooses whether to join.
* **✦ Local Pulse:** Shows only signals generated by this installation or
  received from a real local peer. There is no fake global ticker.

## Privacy and network boundary

There are no external dependencies, accounts, telemetry servers, or hosted
matching services. The daemon uses standard Python UDP sockets and the
Omarchy/Hyprland/MPRIS commands available on the machine.

Runtime requirements are Omarchy Quickshell and Python 3. The optional
presence details use Hyprland's hyprctl and MPRIS busctl; clipboard and
notifications use the usual wl-copy and Omarchy notification commands. No
third-party Python packages are installed.

LAN presence packets are intentionally small and plaintext. They are
unauthenticated and should be treated as discoverable by anyone on the same
broadcast network. Do not use a Friend Code as a secret. Disable LAN radar in
the Beacon tab when you do not want to broadcast, and use the per-field
privacy chips to control project, application, music, theme, and interest
sharing, plus the optional gathering room.

Incoming signals are bounded to twelve per peer per minute. This is a small
anti-spam guard, not authentication or a security boundary.

The plugin does not infer a country, city, or precise location. It does not
claim to discover people on the internet or across Tailscale automatically;
the current transport is local UDP broadcast only.

## Bar controls

* **Left-click:** Open the Friends Deck.
* **Right-click:** Cycle your status.
* **Middle-click:** Copy your Friend Code.
* **Bar pill:** Shows the number of recently observed local peers, or the
  remaining time for an active focus session.
* **Incoming signal:** Adds a desktop notification and a small bar animation.

## Install

    omarchy plugin add https://github.com/harshithnadig/omarchy-friends.git --enable

To place the widget explicitly, add it to the right side of
~/.config/omarchy/shell.json:

    {
      "right": [
        { "id": "community.omarchy-friends" }
      ]
    }

Remove it with:

    omarchy plugin remove community.omarchy-friends

State is stored locally at
~/.local/state/omarchy-friends/friends_state.json (or under
$XDG_STATE_HOME).

## Development and verification

Run the engine tests:

    python3 -m unittest discover -s tests -v

Run the Omarchy checks from the repository root:

    omarchy plugin validate .
    qmllint -I "$OMARCHY_PATH/shell" BarWidget.qml Panel.qml Service.qml
